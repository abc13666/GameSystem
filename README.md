# 🎮 GameSystem — RPG-система ежедневных квестов

> **Статус:** Активная разработка. Проект постоянно улучшается.

Приложение для геймификации повседневных задач. Выполняй действия, получай опыт, прокачивай персонажа и открывай достижения.

---

## 🎯 Концепция

GameSystem превращает обычные дела в RPG-приключение. Каждое выполненное задание даёт опыт, который прокачивает персонажа и открывает новые ранги.
